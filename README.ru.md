# Training Plan — план и отметки тренировок

[English](README.md) · Русский

Небольшой планировщик превращает четырёхнедельный шаблон в список подходов.
Задайте максимумы упражнений на месяц: приложение пересчитает показанные веса и сохранит выполненные подходы на устройстве.
Польза — план, расчёт нагрузки и следующая незавершённая тренировка находятся на одном экране.

## Запуск

Сборка и аккаунт не нужны.

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для установки на телефон разместите файлы через HTTPS, например на GitHub Pages, и добавьте страницу на домашний экран.
Стартовые числа и проценты — искусственный пример. Это не записи тренировок автора и не индивидуальная программа.

## Возможности и границы

- Четыре недели, три тренировочных дня в неделю, редактируемые максимумы и отметки подходов.
- Оценка одноповторного максимума и округление весов по шаблону.
- Прогресс в `localStorage` браузера. Сервера и синхронизации нет.
- Работа без сети после успешной загрузки файлов приложения.

Список упражнений и шаблон заданы в `index.html`. Редактора программы пока нет. Экспорт и импорт JSON работают через текстовое поле.
Список месяцев идёт до декабря 2026 года; после этой даты показывается текущий месяц.
Очистка данных сайта удаляет отметки. Перед сменой браузера или адреса сайта сохраните свою копию данных.
